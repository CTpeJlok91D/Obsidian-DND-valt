#Предмет  #Зелье
Жидкая субстанция, имеющая тёмно-синий цвет.
В любом случае, игрок может использовать зелье, как успокоительное, если персонаж или NPC испытывают сильный стресс.
## Плохое качество:
Выпивший игрок снимает с себя следующие эффекты:
- Страх
- Паника
- Убирает 2d6 очков безумия
 
выпивший игрок бросает куб 1d4 и получает один из эффектов

| Значение | Эффект                                               |
| -------- | ---------------------------------------------------- |
| 1        | Игрок забывает всё, что происходило за последний час |
| 2        | Игрок испытает усталость и засыпает                  |
| 3        | Игрок получает 1d4 урона [[Ядовитый \|ядом]]         |
| 4        | Игрок выпивает зелье без последствий                 |
## Нормальное качество:
Выпивший игрок снимает с себя следующие эффекты:
- Страх
- Паника
- Ошеломлённый
- Убирает 3d6 очков безумия

## Ядовит для некоторых существ
Зелье наносит 1d10 урона всем рептилиям а так же, почему то [[Орк|оркам]].
