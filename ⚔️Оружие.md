# Простое рукопашное оружие
```base
filters:
  and:
  - file.hasTag("#Оружие")
  - Тип == "[[Простое рукопашное оружие]]"
views:
  - type: cards
    name: Table
    order:
      - file.name
      - Стоимость
      - Урон
      - Тип урона
    image: note.Изображение
    imageAspectRatio: 1.5
```
