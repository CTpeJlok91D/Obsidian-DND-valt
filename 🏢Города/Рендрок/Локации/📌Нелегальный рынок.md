#Локация
Нелегальный рынок - место, куда можно попасть, только если среди игроков есть человек, знающий Воровской жаргон. Так как только понимание воровского жаргона позволяет найти туда путь... Либо же просто знать, где проход).

Проход находится недалеко от [[📌Подпольный клуб|подпольного клуба]]

```base
views:
  - type: table
    name: Table
    filters:
      and:
        - file.hasLink(this)
        - file.hasTag("#Событие")
    order:
      - file.name
      - Город
      - Игровая дата
      - Игроки

```
