Возможные результаты:
Мастер бросает бросает d100. Кузнецы и алхимики бросают без помехи.

| Результат броска | Результат создания                                                        |
| ---------------- | ------------------------------------------------------------------------- |
| 1-10             | создание руны не удалось                                                  |
| 11-80            | создание руны удалось                                                     |
| 81-90            | получилось создать 2 руны                                                 |
| 91-100           | получилось создать руну более высокого качества (все эффекты удваиваются) |

От этого же броска зависит время, которое было затрачено:

| Результат броска | Затраченное время |
| ---------------- | ----------------- |
| 1-40             | 5ч                |
| 41-60            | 4ч                |
| 61-80            | 3.5 ч             |
| 81-100           | 3ч                |
