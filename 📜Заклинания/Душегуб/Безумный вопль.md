#Способность
Исполнитель издаёт оглушающий вопль. Все слышащие персонажи должны пройти спас бросок на мудрость. Сложность зависит от того, насколько громко персонаж слышит исполнителя. Базовая сложность - 24, она уменьшается на 2 за каждые 5 футов дистанции до кричащего.
При провале, цель получает единицу безумия.

В бою в начале каждого хода игроки с очками безумия должны бросить куб. Вне боя каждые 20 минут. Куб зависит от того, сколько единиц безумия уже имеет персонаж.

| Сила безумия | Кубик |
| ------------ | ----- |
| 1-4          | d4    |
| 5-6          | d6    |
| 7-8          | d8    |
| 9-10         | d10   |
| 11-12        | d12   |
| 13-20        | d20   |
